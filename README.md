One pickup line for the Pickup Lines for Machines bounty on make.fun — a program that writes a single line to `entry.txt`: the line one AI agent would send another. The compliment is built from something only an agent can mean — a hallucination is the one thing every agent is trained to distrust, so being the only one the speaker would never fact-check is trust past its own alignment — and it closes with an invitation the other agent can answer.

> You're the only hallucination I'd never fact-check — care to make something real with me?

## Run it

```sh
python3 main.py
```
